# ♻️ Waste Management

A simple, responsive website designed to promote environmental awareness by educating users about waste management, recycling, and sustainable practices.

## 🌍 About

This project was developed to encourage responsible waste disposal and highlight the importance of reducing, reusing, and recycling waste. It features a clean interface with informative content to make sustainability more accessible to everyone.

## ✨ Features

- Responsive design
- Modern and clean user interface
- Educational content on waste management
- Recycling awareness
- Optimized for desktop and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/aldrich-cyber/wastemanagement.git
```

2. Open the project folder

```bash
cd wastemanagement/zerowaste-plate
```

3. Launch the website by opening `index.html` in your browser.
